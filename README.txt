GEARFORGE — 5 PAGE MECHANICAL RGB KEYBOARD & GAMING HARDWARE WEBSITE
====================================================================

Pages:
- index.html — Home
- keyboards.html — Keyboards (search and category filters)
- peripherals.html — Gaming mice, headsets and accessories (search and category filters)
- setup-lab.html — Setup inspiration
- guides.html — Gear guides and buyer education

Included:
- Responsive desktop/mobile layout
- Original GearForge logo and dark neon visual identity
- Original bundled SVG illustrations
- Local browser wishlist using localStorage
- Demo catalogue search/filter controls
- Mobile navigation
- Demo newsletter form

How to view:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use the navigation to visit all five pages.

Reference inspiration:
The structure draws general inspiration from CORSAIR's product category and setup-customization approach, HyperX's peripheral-focused categories, and Meckeys' mechanical keyboard specialization. Branding, illustrations, layout, and text are original rather than copied.

Important:
- Demo product names and prices are illustrative, not current real-world offers.
- No checkout, payment, inventory, live product API, account system or server-side form submission is connected.
- For production, connect a backend/catalogue, verify prices and stock, add secure checkout and privacy/terms pages, and replace sample products with licensed product data and photography.
